## 中文

- 书架新增原生 macOS 26 Liquid Glass 风格的 Z-Library 搜索与 EPUB 导入，支持账号会话、最近新增、下载历史、今日额度、日语筛选、排序、详情面板、键盘操作和多书串行导入。
- Z-Library 结果与封面加入独立状态保留、内存/磁盘缓存、受限并发、离屏取消和更可靠的来源 ID / ISBN 重复识别。
- Niratan 现在只发布一个同时包含小说阅读与视频学习的全功能安装包，不再区分 Light / Video 版本。
- Reader 图片库、外观、跳转、统计和 Sasayaki 使用统一的居中原生面板；Sasayaki 新增资源、章节和设置分段，并支持 M4B 内嵌章节跳转。
- 游戏手柄设置与键盘快捷键共享完整动作列表；Anki 字段映射改用单层原生 Liquid Glass 可编辑下拉输入框，并继续保留自定义或明确清空的映射。

## English

- The Bookshelf now provides a native macOS 26 Liquid Glass Z-Library search and EPUB import experience with account sessions, recent books, download history, daily quota, Japanese filters, sorting, details, keyboard navigation, and serial multi-book imports.
- Z-Library results and covers now preserve independent state and use memory/disk caching, bounded concurrency, off-screen cancellation, and more reliable source-ID/ISBN duplicate detection.
- Niratan now ships one full-feature installer containing both book reading and video learning, replacing the separate Light and Video editions.
- Reader image gallery, appearance, navigation, statistics, and Sasayaki use consistent centered native panels. Sasayaki adds Resources, Chapters, and Settings sections with direct M4B chapter seeking.
- Game Controller settings share the complete Keyboard Shortcuts action catalog. Anki field mappings now use a single native Liquid Glass editable menu field while preserving custom and explicitly cleared mappings.
