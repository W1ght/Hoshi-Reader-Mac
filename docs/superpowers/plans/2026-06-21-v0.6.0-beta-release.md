# v0.6.0 Beta Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `v0.6.0-beta` as a GitHub prerelease containing Light and Video native macOS DMGs and SHA-256 checksums.

**Architecture:** Keep the public prerelease identifier separate from the app bundle marketing version. Tags, artifact names, release titles, and notes use `0.6.0-beta`; Xcode and the built app use `0.6.0`. GitHub Actions derives prerelease status from the hyphenated version and publishes both existing variants.

**Tech Stack:** Bash, GitHub Actions, Xcode build settings, `gh`, native macOS DMG packaging.
